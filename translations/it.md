# AURA Switcher — Italian (it) translation

Italian is already in the app and on the site (https://klbk.github.io/aura-switcher/it/), but it was not written by a native speaker. Please proofread it: fix anything that sounds unnatural or wrong, and leave good lines as they are.
Keep the key before `=`, HTML tags (<br>, <kbd>, <span …>), {v} and symbols (⇧ ⚠︎ ⬆︎ ☕ →) unchanged.
When done, open a pull request with this file. The maintainer will move the texts into the app and the site.
